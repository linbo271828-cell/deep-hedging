# REFLECTION.md — Deep Hedging Lab

## 1. Describe your process. At a high level, how did you go about creating this project?

A while ago I came across this interesting paper from Buehler regarding hedging, and I spent sometime this semester reading
through it. Honestly when i started the project I still didn't fully undertstand everything or even finish it however i used
this opportunity to learn and further my understanding. I started with the math, and then moved to developing a really fleshed out spec, this was done with the assistance of chatgpt to come up with a markdown file of the spec aswell as all future prompts I sent to claude or claude code were all designed and generated by chatGPT. I would then send these prompts to claude code where it executed them and created my project.


## 2. What AI tools and strategies did you use? What models did you choose, and were you using them in a browser chat, in something like Cursor, in the command line, etc.? Did you use an agentic process like in HW8, or something else?

I used Claude Code (CLI) with a mix of mostly Sonnet 4.6 but also Opus 4.7. For promptying as mentioned I used ChatGPT 5.5 which I used the desktop version. For most of the task of building my project, I instructed claude with the prompt engineering from chatGPT 5.5 to use an team agent strategy to build the project, delegating different sections for different claude agents and also these agents had different models like Sonnet 4.6 or Opus 4.7 depending on the difficulty of the task.


## 3. Why did you make the choices above?

Obviously ideally I wanted Opus 4.7 to be used for every part of the project, but the main issue was the limited amount of tokens I had at hand. Thus I carefully only chose to utilize Opus 4.7 on a sepcific difficult task when running parallel or single agent.
